# 算数プロジェクト (Arithmetic Project)

基本的な算数演算を行うPythonプログラムと、クイズゲームを含むプロジェクトです。

## プログラム

### 1. 算数計算機 (calculator.py)

基本的な算数演算を提供する対話型計算機です。

**機能:**
- **加算** (+): 2つの数を足します
- **減算** (-): 2つの数を引きます
- **乗算** (*): 2つの数を掛けます
- **除算** (/): 2つの数で割ります（0除算チェック付き）

### 2. クイズゲーム (quiz_game.py)

2問連続で正解するとクリアとなる算数クイズゲームです。

**特徴:**
- ランダムな算数問題（加算、減算、乗算）が出題されます
- 2問連続で正解するとゲームクリア
- 不正解の場合は連続正解カウントがリセットされます
- 何度でも挑戦可能

## 使い方

### 算数計算機を実行

```bash
python3 calculator.py
```

プログラムを実行すると、メニューが表示され、演算を選択して計算できます。

### クイズゲームを実行

```bash
python3 quiz_game.py
```

ゲームを開始すると、算数の問題が出題されます。2問連続で正解を目指しましょう！

### Pythonモジュールとして使用

```python
from calculator import add, subtract, multiply, divide

# 加算
result = add(5, 3)  # 8

# 減算
result = subtract(10, 4)  # 6

# 乗算
result = multiply(3, 7)  # 21

# 除算
result = divide(20, 4)  # 5.0
```
